# 五线谱小课堂

给小朋友的五线谱识谱 / 读谱练习工具（Web 版，WinUI / Fluent 风格界面）。

## 打开方式

- **直接双击** `index.html`（无需任何环境，Chrome / Edge 均可）
- 或启动本地服务器：`node server.js`，然后访问 http://localhost:8123
- **iPad 使用**：
  - **推荐**：部署到 GitHub Pages（HTTPS），麦克风跟练、离线缓存、添加到主屏幕全部可用
    → 见 [部署到 GitHub Pages](docs/部署到GitHub-Pages.md)
  - 局域网：电脑跑 `node server.js`（会打印局域网 IP），iPad 与电脑连同一 Wi-Fi，Safari 打开 `http://电脑IP:8123`
    （http 下麦克风跟练不可用，其余功能正常）

## 功能

- **✏️ 识谱练习（四种玩法）**：
  - 👆 点音名：看谱点 Do Re Mi（或 C D E）
  - 🎹 点琴键：看谱后在钢琴键盘上按对应琴键
  - 👂 听音辨键：先听音，再点琴键（可重播）
  - ✍️ 放音符：看音名，在五线谱上点击放置音符（↑↓ 微调）
  - 答对加分加星、播放钢琴音；答错可重试；连对有 🔥 计数
  - ⌨️ 快捷键：A S D F G H J = 白键，W E T Y U = 黑键，1–7 = 唱名
- **🎹 88 键模式**：难度选「88 键」后出题覆盖钢琴全部 88 个琴键（含黑键，谱上显示 ♯），
  谱号按音区自动选择，极端音高加线自动延伸。
- **🎮 游戏化激励**：XP 升级等级条、每日练习连击（连续天数）、每日任务、
  6 枚成就徽章、升级/徽章/任务完成全屏庆祝动画。
- **🎓 课程闯关（三本教材体系）**：
  - 📗《孩子们的拜厄》上下册（入门启蒙，12 课）：琴键/手位/时值/节拍/休止符/升降号/双手配合
  - 📘《钢琴基础教程》四册（系统进阶，15 课）：五线谱/谱号/音阶/听音/放音符
  - 🖐️《孩子们的哈农》（手指功夫，10 课）：手型/断奏连奏/五指练习/音阶琶音/穿指
  - 每课含知识点讲解（配五线谱示意图）+ 配套练习，线路内顺序解锁、
    答对 5 题过关、按一次答对率给 1–3 星，三线进度各自独立保存。
- **🎵 曲谱库**：36 首曲目，按「经典儿歌 / 教材」分组——
  - 经典儿歌 10 首（小星星/欢乐颂/铃儿响叮当/卡农/致爱丽丝/小步舞曲等）
  - **教材曲库 91 首**：
    - 教材：小汤 1–4 册 14 首、拜厄 17 首、车尔尼 599 30 首
    - 曲集：世界民歌 7 首、中国民歌 5 首、古典名曲 10 首、音阶琶音 8 首
  - **89 首带左手伴奏**，伴奏长度自动与旋律对齐，分手/双手跟练都有内容可练
  - 谱面按时值渲染（全/二分/四分/八分音符，含黑键 ♯），长曲横向滚动、**分段播放**
    （按 4 小节切分），Web Audio 逐音播放并高亮，「找音练习」随机抽曲中一个音答题。
- **🎤 唱谱练习 / 🎹 跟弹练习（实时纠错，对标小叶子）**：
  小朋友在真钢琴/电钢琴上弹（或唱），麦克风实时识别音高，**按起音推进而不是卡住等对**，
  可以自由速度弹完整首——
  - 弹对变绿、弹错标红、漏弹标橙，错误留在谱面上可回看
  - **节奏判定**：按相邻音的时值比例识别抢拍/拖拍（自动归一化整体速度）
  - **变速练习** 50–120 BPM、**节拍器**、**预备拍**、**分段循环**、**分手 / 🤝 双手合练**
  - **🎙 录音回放**：跟练同时录下演奏，报告里直接回放对比（只存内存，可删除）
  - 练完出**多维度报告**：音准 / 节奏 / 完整度 + 星级 + 错音漏音位置 + 最高连对
  - **🎹 MIDI 键盘输入**：连接电钢琴后音高精确、和弦直接识别，不受环境噪声影响
    （Chrome/Edge 支持，自动降级回麦克风）
  - 结果计入 XP、每日任务与徽章
  （麦克风需要 https/localhost 环境与权限）
- **🎯 训练营（三项基本功）**：
  - 👀 **视奏**：随机生成没见过的两小节谱，30/25/20/18 秒内按顺序弹/唱，四档难度（含低音谱号与黑键）
  - 🧠 **乐理**：54 道选择题，13 个分类（谱号/五线谱/音符/休止符/拍号/音名/升降号/音程/和弦/力度/速度/记号/指法/乐曲），每题带解析
  - 👏 **节奏**：跟节拍器在标记处打拍，三档节奏型（四分/八分/切分/附点/三连音），自动对齐整体延迟
  - 📕 **错题本**：自动记录答错的音并按次数排序，一键生成 10 题专项练习
  - 📈 **练习记录**：最近 7 天练习量柱状图 + 天数 / 次数 / 正确率汇总（保留 30 天）
- **📖 认识五线谱**：音阶一览 + 钢琴键盘双向联动；88 键模式下键盘为完整 88 键。
- **⚙️ 设置**：高音/低音/随机谱号、简单/标准/88键难度、唱名/音名切换、八度判定宽容/严格、声音开关；
  成绩与进度保存在本地浏览器。重置分「统计 / 课程 / 全部」三档，互不影响。
- **♿ 可访问性**：导航与琴键支持方向键操作、跳转链接、焦点环、减少动效偏好、触摸优化；
  分组控件带 `aria-pressed`，徽章说明常驻显示，庆祝动画可点击/Esc 关闭。
- **📱 移动端**：刘海屏安全区、横屏紧凑布局、平板大按键、横向惯性滚动。
- **👧 多儿童档案**：一台设备可建 1–8 个小朋友档案（名字 + 头像），
  成绩、课程、徽章、错题本各自独立；顶部头像一键切换，旧数据自动迁移。
- **⚡ 每日挑战**：每天 8 题、限时 60 秒（6 道识谱 + 2 道乐理），同一天题目固定；
  全对累计 3 天解锁限定徽章「🏆 每日之星」。
- **🏅 成就墙**：7 枚徽章显示说明、获得日期与进度条，未获得的能看到还差多少。
- **👨‍👩‍👧 家长周报**：按小朋友统计最近 7 天——练习天数、次数、一次答对率、每日柱状图、
  练习类型分布、最需要加强的音，并自动生成 3 条给家长的建议；支持一键复制文字版。
- **💾 数据备份**：一键导出 JSON 备份；导入时可选「合并」（进度取更优）或「覆盖」，
  损坏文件会被拒绝且不影响现有数据。
- 亮色/深色主题（儿童化糖果色亮主题）。

## 技术

纯前端 HTML + CSS + JS（无构建、无依赖），SVG 渲染五线谱，Web Audio 合成钢琴音。

```
index.html        页面结构
style.css         WinUI/Fluent 风格（Mica 背景、Acrylic 卡片、主题变量）
js/core.js        音高映射 / 坐标 / 出题（纯逻辑，可 node 测试）
js/follow.js      跟练引擎：起音检测 / 错音漏音匹配 / 节奏评分（纯逻辑）
js/midi.js        Web MIDI 接入（电钢琴输入）
js/stats.js       错题本 + 练习历史（纯逻辑）
js/recorder.js    跟练录音与回放（MediaRecorder）
js/backup.js      数据备份：导出 / 校验 / 合并导入（纯逻辑）
js/profiles.js    多儿童档案：存储、迁移、校验（纯逻辑）
js/weekly.js      家长周报：汇总、评级、建议生成（纯逻辑）
js/challenge.js   每日挑战：固定种子出题、判分、徽章条件（纯逻辑）
js/sight.js       视奏生成、乐理题库、节奏打拍评分（纯逻辑）
js/library.js     教材对齐曲库（小汤 / 拜厄 / 车尔尼 599）
js/glyphs.js      谱号轮廓数据（取自 Bravura 音乐字体，SIL OFL 1.1）
js/staff.js       SVG 五线谱渲染 + 钢琴键盘
js/audio.js       Web Audio 钢琴音合成
js/app.js         应用逻辑（练习 / 学习 / 设置 / 持久化）
server.js         本地静态服务器
```

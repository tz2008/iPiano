## 1. 产品概述

### 1.1 定位

面向 **4–10 岁钢琴初学儿童** 的五线谱识谱训练工具。核心价值是“**看谱 → 说出/弹出音 → 立即反馈**”，并把练习包装成闯关与收集，降低识谱的枯燥感。

### 1.2 形态

- 纯前端单页 Web 应用（PWA），无后端、无账号、无网络依赖。
- 运行环境：桌面 Chrome / Edge；iPad Safari（添加到主屏幕后全屏、离线）。
- 数据存储：浏览器 `localStorage`，单机、不上传。

### 1.3 核心能力

| 能力 | 说明 | 当前状态 |
|---|---|---|
| 看谱识音 | 五线谱显示音符，点音名 / 点琴键作答 | ✅ |
| 听音辨键 | 播放音高，在键盘上找音 | ✅ |
| 写谱 | 看音名，在五线谱上放音符 | ✅（有缺陷，见 §10.1） |
| 系统课程 | 三套教材、30 课、顺序解锁 | ✅ |
| 曲谱库 | 10 首公版旋律，播放 / 找音 / 跟练 | ✅（黑键渲染缺陷，见 §10.1） |
| 麦克风跟练 | 整曲实时纠错：错音/漏音/节奏，分段循环、变速、节拍器 | ✅（需 https/localhost） |
| 视奏 / 乐理 / 节奏 | 随机视奏、54 题乐理、打拍训练 | ✅ |
| 教材曲库 | 小汤 / 拜厄 / 车尔尼 599 共 26 首 | ✅ |
| MIDI 键盘 | 电钢琴精确输入，和弦识别 | ✅ |
| 错题本 / 练习记录 | 弱项专项练习、7 天趋势 | ✅ |
| 游戏化 | XP、等级、日连击、每日任务、徽章 | ✅ |

### 1.4 设计原则

1. **零门槛**：双击 `index.html` 即可用，不需要安装、注册、联网。
2. **不惩罚**：答错只给方向提示，不扣分；连对与星级是正向激励。
3. **儿童友好**：大按钮、糖果色、Emoji 图标、鼓励语、全屏庆祝动画。
4. **家长可读**：所有进度本机保存，设置页可见成绩与徽章。

## 2. 用户与场景

### 2.1 角色

| 角色 | 特征 | 主要诉求 |
|---|---|---|
| 儿童（主用户） | 4–10 岁，识字有限，操作以点按为主 | 好玩、有反馈、有奖励 |
| 家长（次用户） | 陪同练习，负责选课与看进度 | 课程有体系、进度可见、可重置 |
| 钢琴老师（可选） | 布置识谱作业 | 能指定谱号/难度/曲目 |

### 2.2 典型场景

1. **每日 10 分钟练习**：打开 → 识谱练习 → 完成 3 个每日任务 → 看徽章。
2. **按教材闯关**：课程页 → 拜厄第 1 课 → 看知识点 → 答对 5 题 → 3 星过关。
3. **学新曲**：曲谱库 → 小星星 → 听播放 → 找音 → 跟弹（麦克风）。
4. **认识键盘**：认识五线谱页 → 点琴键 → 看它在谱上的位置与音名。

## 4. 功能规格：识谱练习

### 4.1 出题

#### 4.1.1 音域与谱号

| 难度 | 高音谱号范围 | 低音谱号范围 | 说明 |
|---|---|---|---|
| 简单 easy | C4–B4（7 个自然音） | G2–A3（9 个自然音） | 谱表内，无加线 |
| 标准 standard | C4–A5（13 个自然音） | E2–C4（13 个自然音） | 含上下各一条加线 |
| 88 键 full | A0–C8（全部 88 键） | 同左 | 含黑键，谱号按音区自动选 |

规则：

- **谱号自动选择**（88 键难度）：`MIDI ≥ 60（C4）→ 高音谱号`，否则低音谱号。
- **随机谱号**：每 50% 概率高音 / 低音。
- 出题在范围内**均匀随机**，不排除重复，不做难度递进。
- 黑键以「下方白键 + ♯」表示（如 C♯4 = midi 61，显示在 C4 位置加 ♯）。

#### 4.1.2 四种模式

| 模式 | 题目呈现 | 作答方式 | 判定规则 |
|---|---|---|---|
| 👆 点音名 `name` | 谱上显示一个音符 | 7 个（或 12 个）音名按钮、键盘快捷键 | **只判音级**（音名相同即对），不判八度 |
| 🎹 点琴键 `keyboard` | 谱上显示一个音符 | 迷你钢琴键盘 | **必须精确匹配 MIDI**（含八度） |
| 👂 听音辨键 `listen` | 谱面为空，自动播放目标音 | 迷你钢琴键盘、快捷键 | 同 keyboard；快捷键只判音级 |
| ✍️ 放音符 `place` | 谱面为空，提示“请把「X」放到五线谱上” | 点击谱面放置、↑↓ 微调、确认 | **必须精确匹配 MIDI** |

⚠️ 现状偏差：四种模式的判定宽严不一致（§10.1-3）；`place` 模式会同时显示迷你键盘，可直接点键作答（§10.1-2）；`listen` 的“再听一次”按钮永远不会显示（§10.1-1）。

### 4.2 作答与反馈

#### 4.2.1 答对

1. 按钮变绿 / 琴键高亮，播放目标音（`playDing`）。
2. 反馈语：连对 ≥ 5 时显示“🔥 连续答对 N 题！”，否则随机鼓励语；本题曾答错则固定“答对啦！下次一次就答对更棒！”。
3. 提示行显示正确答案名称。
4. **1100ms 后自动进入下一题**。

#### 4.2.2 答错

- 立即中断连对（`currentStreak = 0`）。
- 按钮/琴键标红；`name` 模式该按钮禁用；播放“错误提示音”（220→180Hz 短音）。
- 第一次答错：显示方向提示（“你猜高了/低了 N 个半音”）+“还剩 1 次机会”。
- **第二次答错**：高亮正确按钮、谱面显示答案、播放目标音 1 秒，反馈“答案揭晓：X”，**2200ms 后自动下一题**（本题不再要求答对）。

⚠️ 现状偏差：页面文案写“答错了没关系，可以再试，直到答对为止”，与“2 次错后揭示并跳过”冲突（§10.1-4）。

### 4.3 计分

| 指标 | 定义 | 存储字段 |
|---|---|---|
| 尝试次数 | 每次作答（含答错）都 +1 | `stats.attempts` |
| 答对题数 | 答对的题目数 | `stats.correct` |
| 一次答对 | 本题未答错即答对的次数 | `stats.firstTry` |
| 星数 | 一次答对 +2，答错后答对 +1 | `stats.stars` |
| 当前连对 | 连续“一次答对”的题数，答错归零 | `stats.currentStreak` |
| 最佳连对 | 当前连对的历史最大值 | `stats.bestStreak` |
| 88 键答对 | 88 键难度下的答对次数 | `stats.fullCorrect` |
| 一次答对率 | `firstTry / correct` | 派生 |

✅ 已修复：尝试次数、答对题数、星数三者语义分离；设置页展示 5 项指标（尝试/答对/一次答对/最佳连对/累计星数）。

### 4.4 快捷键

| 场景 | 按键 | 行为 |
|---|---|---|
| 点音名（7 键） | `A S D F G H J` | Do Re Mi Fa Sol La Si |
| 点音名（7 键） | `1 2 3 4 5 6 7` | 同上 |
| 点音名（88 键） | `A W S E D F T G Y H U J` | C C♯ D D♯ E F F♯ G G♯ A A♯ B |
| 点琴键 / 听音 | 同上 12 键 | 按半音类判定 |
| 放音符 | `↑` / `↓` | 上/下一个自然音 |
| 放音符 | `Enter` | 提交 |

约束：忽略长按重复、忽略输入框内按键。

⚠️ 现状偏差：未过滤 Ctrl/Meta/Alt 组合键；数字键在 88 键模式下无效（§10.2-2）。

### 4.5 课程练习中的差异

课程练习时：

- 模式、谱号、难度**完全由课程指定**，用户设置不生效。
- 模式切换条隐藏。
- 顶部显示课程横幅（课程名 + 进度 N/目标）。
- 达到目标题数即结算（见 §5.3）。

## 5. 功能规格：课程闯关

### 5.1 教材体系

| 线路 | 名称 | 定位 | 课数 | ID 规则 |
|---|---|---|---|---|
| `baier` | 孩子们的拜厄 | 入门启蒙 · 上下册 | 12 | `baier-01` … `baier-12` |
| `jichu` | 钢琴基础教程 | 系统进阶 · 四册 | 15 | `jichu-01` … `jichu-15` |
| `hanon` | 孩子们的哈农 | 手指功夫 | 10 | `hanon-01` … `hanon-10` |

合计 37 课，三条线路进度**完全独立**。

### 5.2 课程数据模型

```js
{
  id: 'baier-01',          // 全局唯一
  line: 'baier',           // 所属线路
  book: '上册',            // 分册标签
  title: '认识琴键与中央 C',
  icon: '🎹',
  points: [                // 知识点卡片（HTML 片段）
    { title: '钢琴的键盘', html: '<p>…</p>' }
  ],
  staffDemo: {             // 可选：五线谱示意图
    clef: 'treble',
    notes: [60, 62, 64, 65, 67],
    caption: '…'
  },
  practice: {              // 本课练习配置
    clef: 'treble',        // treble | bass | random
    difficulty: 'easy',    // easy | standard | full
    mode: 'name',          // name | keyboard | listen | place
    target: 5              // 过关题数
  }
}
```

新增课程：拜厄 11–12（八度、休止符）、基础教程 13–15（附点、G 大调、三和弦）、哈农 9–10（同音换指、双音）。

注：部分课程未配 `staffDemo`（以文字知识点为主）。

### 5.3 解锁、过关与星级

**解锁**：同线路内，上一课 `done` 后本课解锁；每线第一课默认解锁；无星级门槛；线路之间互不影响。

**过关**：本课答对题数达到 `practice.target`（当前全部为 5）。

**星级**（按一次答对率）：

| 一次答对率 | 星级 |
|---|---|
| ≥ 90% | ⭐⭐⭐ |
| 70% – 89% | ⭐⭐ |
| < 70% | ⭐ |

**持久化**：`state.courses[id] = { done: true, stars }`；重玩时**星级只升不降**。

**结算流程**：全屏庆祝“🎓 过关啦！” → 1800ms 后返回课程列表 → 下一课解锁。

⚠️ 现状偏差：重玩拿低星时，提示语显示本次星级而存储保留旧高星，两者不一致（§10.2-4）；退出课程不确认、不保存课中进度（§10.2-5）。

## 6. 功能规格：曲谱库与跟练

### 6.1 曲目数据模型

```js
{
  id: 1,
  title: '小星星',
  origin: '法国民歌',
  level: '入门',
  key: 'C 大调',
  notes: [[60, 1], [60, 1], [67, 1], …],  // [MIDI, 时值（四分音符=1）]
  bass:  [[48, 4], …]                     // 可选：左手伴奏
}
```

曲目分两组，共 46 首（全部公版）：

| 分组 | 数量 | 内容 |
|---|---|---|
| 经典儿歌 | 10 | 小星星、欢乐颂、铃儿响叮当、玛丽有只小羊羔、两只老虎、划船歌、伦敦桥、D 大调卡农（主题）、致爱丽丝（主题）、G 大调小步舞曲（开头） |
| 教材 · 小汤 1–2 册 | 8 | 玛丽有只小羊羔、小蜜蜂、划船歌、欢乐颂、铃儿响叮当、两只老虎、伦敦桥、小星星 |
| 教材 · 小汤 3 册 | 3 | 欢乐的牧童（主题）、春之歌（主题）、平安夜 |
| 教材 · 小汤 4 册 | 3 | 摇篮曲、小步舞曲（G 大调主题）、铃儿响叮当（完整版） |
| 教材 · 拜厄 | 17 | No.1–No.17（五指、音阶、三度/五度、附点、G/F/D 大调、十六分、分解和弦、切分、三连音、琶音、左手旋律） |
| 教材 · 车尔尼 599 | 15 | No.1–No.15（五指、级进、十六分、模进、分解和弦、G/F 大调） |

**左手伴奏**：46 首中 44 首带伴奏（拜厄 No.2 与 No.17 为纯左手曲，无伴奏）。
伴奏以 4 拍长音为主，构成 I–V–vi–IV 的简化和声；载入时由 `normalizeBass` 自动把伴奏总拍数
补齐/裁齐到与旋律一致，保证左手与双手跟练不会因“伴奏先结束”而中断。

**教材曲库字段**：在通用字段基础上增加 `book`（分组名）与 `clef`（旋律谱号，拜厄 No.2 为低音谱号）。

### 6.2 谱面渲染

- 固定高音谱号（左手跟练时切换为低音谱号）。
- 每音横向间距 34px；时值通过符头/符干/符尾表现：
  - 4 拍及以上：全音符（空心、无符干）
  - 2–3 拍：二分音符（空心 + 符干）
  - 1 拍：四分音符（实心 + 符干）
  - 1 拍以下：八分音符（实心 + 符干 + 符尾）
- 高亮态：当前音闪烁 + 光晕；已过音绿色；弹错音红色；漏弹橙色；非当前段落变淡。
- **黑键音符自动渲染**为「下方白键 + ♯」，符头、加线、符干均按白键位置计算。
- **长曲横向滚动**：按真实像素宽度渲染，容器 `.scroll-x` 横向滚动；播放/跟练时自动滚动到当前音。

✅ 已修复：黑键不渲染（卡农 32 音全部可见）、长曲被压缩重叠。

### 6.3 播放

- 逐音播放，音长 `max(0.5, 时值 × 0.55)` 秒。
- 速度档：慢（0.6×）/ 中（1×，默认 120 BPM）/ 快（1.4×），选择器与实际速度保持一致。
- **分段播放**：按 4 小节切分（如「第 1 段（第 1–15 音）」），可只播放某一段。
- 播放时当前音高亮跳动并自动滚动；可随时停止。
- 只播放旋律，不播放左手伴奏。

✅ 已修复：速度档 UI 与实际不一致、停止按钮文案不恢复。

### 6.4 找音练习

1. 从曲目中随机抽一个音，谱面闪烁高亮。
2. 作答按钮：曲中含黑键时 12 个（含升号），否则 7 个；写法跟随“答案写法”设置。
3. 判定：按音级匹配（不要求八度）。
4. 答对：播放提示音，显示音名与位置，1300ms 后自动下一题。
5. 答错：该按钮标红并禁用，可继续排除作答。

⚠️ 现状偏差：答错提示“再听听”，但并不播放目标音；无得分、无次数限制（§10.2-7）。

### 6.5 唱谱 / 跟弹（麦克风跟练）

**前置条件**：`navigator.mediaDevices.getUserMedia` 可用（https 或 localhost），否则按钮不显示并提示。

**模式**：

| 模式 | 输入 | 判定 |
|---|---|---|
| 唱谱 `sing` | 麦克风识别人声 | 单音 |
| 跟弹 `piano` | 麦克风识别钢琴 | 单音 |
| 双手合练 `both` | 麦克风复音检测 | 右手旋律 + 左手伴奏同时正确 |

**手选择**：有左手伴奏的曲目可选右手 R / 左手 L；跟弹模式额外提供“双手合练”。

**输入源**：麦克风 或 🎹 MIDI 键盘（Web MIDI；Chrome/Edge 支持，连接失败自动降级）。
MIDI 输入音高精确、和弦直接识别，不受环境噪声影响，是首选输入方式。

**练习方式（实时纠错，对标小叶子）**：

| 能力 | 规则 |
|---|---|
| 推进方式 | **按起音推进**：音高稳定 ≥55ms 即视为一次起音，弹对立即进入下一音，不等固定时长 |
| 音准容差 | ±0.5 半音 |
| 八度折叠 | 差 12 个半音视为同音（错八度也算对） |
| 错音 | **不卡住**：标红该位置并继续往下（评估模式），状态栏提示正确音 |
| 漏音 | 直接弹后面第 1–2 个音时，中间的音标记为「漏弹」（橙色） |
| 和弦（双手） | 左右手两个音都出现即通过，不要求同时按下 |
| 节奏 | 按相邻起音的时值比评分，中位数归一化后识别抢拍/拖拍 |
| 变速 | 50–120 BPM，8 档 |
| 节拍器 | 可开关，每小节首拍重音 |
| 分段 | 按 4 小节切分，可单独练某段 |
| 循环 | 可开关，练完自动回到段首 |
| 预备拍 | 可开关（默认开）；开始前 4 拍倒计时，首拍重音，期间不采集、不计分 |
| 录音 | 可开关；复用麦克风流录下整段练习，报告里可回放/删除（仅存内存） |

**练习报告**：

| 字段 | 口径 |
|---|---|
| 音准 | `(总音数 − 错音数 − 漏音数) / 总音数` |
| 节奏 | 时值准确的比例（归一化后误差 ≤35% 记为准确） |
| 完整 | 正确起音数 / 总音数 |
| 星级 | 综合分 = 音准 × 70% + 节奏 × 30%；≥92 三星、≥75 二星、否则一星 |
| 最高连对 | 本次最佳连对 |
| 错音 / 漏音位置 | 第 N 个音列表 |
| 评语 | 按星级给出 |

**结果计入**：统计（`stats.followRuns / followStars / followPerfect`）、XP（3 + 星级）、每日任务、徽章。
中途结束（未弹完整段）时，标题显示“本次练习”，星级最高 2 星，不按满星计。

**录音**：开启录音后复用跟练的麦克风流，不额外申请权限；录音只存在内存，离开页面或重练即丢弃。
MIDI 输入没有音频流，切到 MIDI 时录音自动关闭并提示。

**生命周期**：离开曲谱页、切到后台、开始跟练时都会停止麦克风与节拍器。

✅ 已修复：左手跟练无法结算、正确率口径、换手不清累计状态、报告不进统计、离开页面不停麦克风。

## 7. 功能规格：训练营（视奏 / 乐理 / 节奏）

一级页面「🎯 训练营」，三个标签页共用一套结果记录（`stats.trainRuns / trainStars / trainPerfect`、`state.trainBest`），
完成后计入 XP（2 + 星级）、每日任务与徽章。

### 7.1 视奏

**目的**：训练“第一次看到谱就能弹”的能力，区别于识谱练习（已认识的音）和跟练（已练过的曲）。

**流程**：

1. 选择难度（入门 / 初级 / 中级 / 进阶）。
2. 系统随机生成 **2 小节**没见过的谱，渲染到五线谱上。
3. 倒计时开始（30 / 25 / 20 / 18 秒）。
4. 用麦克风逐音弹/唱，或用键盘 `A S D F G H J` 作答。
5. 按顺序对照，时间到或弹完即结算。

**难度参数**：

| 难度 | 谱号 | 音域 | 时值 | 音程跳进 | 黑键 | 限时 |
|---|---|---|---|---|---|---|
| 入门 | 高音 | C4–C5 | 四分、二分 | 二度、三度 | 无 | 30s |
| 初级 | 高音 | C4–F5 | 加八分 | 至四度 | 无 | 25s |
| 中级 | 高音 | G3–A5 | 加全音符 | 至五度 | 无 | 20s |
| 进阶 | 高/低音随机 | C3–C6 | 同上 | 至六度 | 有（约 12%） | 18s |

**评分**：只判音高与顺序（不判节奏）。正确率 = 正确音数 / 总音数；≥95% 三星、≥80% 二星、否则一星。

**生成规则**：起始音落在音域中部；按音级步进（不是半音），超出音域自动反向；每小节时值合计等于拍号。

### 7.2 乐理

**题库**：54 道单选题，每题 4 个选项 + 解析，覆盖 13 个分类：

| 分类 | 示例 |
|---|---|
| 谱号 | 高音谱号为什么叫 G 谱号 |
| 五线谱 | 一线/三线是什么音、加线 |
| 音符 | 全/二分/四分/八分时值、符干符尾 |
| 休止符 | 含义、全休止符 |
| 拍号 | 4/4、3/4、2/4 的含义与位置 |
| 音名 | 唱名对应、八度半音数、88 键 |
| 升降号 | ♯ ♭ ♮、调号位置、G/F/C 大调 |
| 音程 | 三度/五度/八度 |
| 和弦 | 大三和弦构成、大小三和弦区别 |
| 力度 | f / p / cresc. |
| 速度 | Adagio / Allegro |
| 记号 | 连音线、跳音、延长、反复 |
| 指法 | 1–5 指 |
| 乐曲 | 小星星、欢乐颂、致爱丽丝 |

**流程**：选分类（或全部）→ 抽 10 题（不重复）→ 逐题作答 → 立即判定并显示解析
（答对 0.9s 后下一题，答错 2.2s 后下一题）→ 10 题结束给出星级。

**评分**：正确率 ≥90% 三星、≥70% 二星、否则一星。

### 7.3 错题本

- 自动记录答错过的音（按**音级**聚合，最多 12 个键），并统计错误次数与错误率。
- 列表按错误次数降序展示，标注每个音常用谱号。
- 「🎯 练这些音」：从最薄弱的 6 个音中随机抽，生成 10 题音名专项练习。
- 「清空错题本」：二次确认后清空。
- 数据字段：`state.mistakes[pitchClass] = { wrong, total, last, clef }`。

### 7.4 练习记录

- 按天记录各类练习次数、答对/总题数与用时，保留最近 **30 天**。
- 页面展示最近 7 天：练习天数、完成次数、正确率三项汇总 + 每日柱状图。
- 记录来源：识谱练习（每题）、跟练（每次结算）、视奏/乐理/节奏（每轮）。
- 数据字段：`state.history['YYYY-MM-DD'] = { practice, follow, sight, theory, rhythm, correct, total, seconds }`。

### 7.5 节奏

**目的**：在没有音高的干扰下单独训练时值感。

**流程**：

1. 选择难度（入门 / 初级 / 中级）。
2. 生成一个 4 拍的节奏型，用 👏 标出需要打拍的位置。
3. 先听 **4 拍预备拍**（首拍重音）。
4. 在 👏 处点击大按钮或按 **空格键** 打拍。
5. 节奏型走完后结算。

**节奏型**：

| 难度 | 内容 |
|---|---|
| 入门 | 四分音符、二分音符、全音符 |
| 初级 | 八分音符、四分 + 八分组合 |
| 中级 | 切分、附点、三连音 |

**评分**：以 45% 格子时长为容差做匹配；**自动对齐整体延迟**（孩子整体慢半拍也算对，
报告里单独给出延迟毫秒数）。准确率 ≥90% 三星、≥70% 二星、否则一星。

### 8.2 认识五线谱

- 显示当前谱号下的完整音阶（高音 C4–C6 共 15 个自然音；低音 E2–C4 共 13 个）。
- 点音符：播放该音、在下方键盘高亮、显示音名与唱名。
- 点琴键：播放实际音高；黑键在谱上以「下方白键 + ♯」显示，音阶外的音追加到谱面右侧。
- 88 键难度下键盘显示完整 88 键（52 白 + 36 黑）。

### 8.3 设置项

| 设置 | 取值 | 默认 | 影响范围 |

| 谱号 | 高音 / 低音 / 随机 | 高音 | 练习出题、学习页 |

| 主题 | 浅色 / 深色 | 浅色 | 全局配色 |

### 8.4 数据备份

**动机**：数据只存在本机 localStorage，iPad 长期不用可能被系统清理，换设备也无法带走。

**导出**（导出当前档案）：

- 设置页「⬇️ 导出备份」→ 下载 `五线谱小课堂-备份-YYYYMMDD-HHmm.json`。
- 文件的 `meta.profileName` 记录来源档案名，导入时会显示。
- 文件格式：

```jsonc
{
  "format": "ipiano-backup",   // 固定标识
  "version": 1,                // schema 版本
  "exportedAt": "2026-10-21T07:19:00.000Z",
  "app": "五线谱小课堂",
  "data": { /* 与 localStorage 完全相同的 state */ }
}
```

**导入**：

1. 「⬆️ 导入备份」选择文件（限 2MB）。
2. 校验：非 JSON、非本应用、版本高于当前 → 拒绝，**不改动现有数据**。
3. 校验通过后弹确认框，显示备份时间与内容概览，并让用户选择：
   - **确定 = 合并**：进度取更优（统计取大、课程取高星、徽章取并集、错题本与历史相加），
     偏好设置保留本机。
   - **取消 = 覆盖**：完全采用备份数据（含偏好设置）。
4. 导入后立即刷新全部界面并保存。

兼容性：也接受不含 `format` 字段的裸 state（手工保存的旧文件）。

### 8.5 成绩与重置

**显示**：尝试次数、答对题数、一次答对、最佳连对、累计星数。

## 9. 家长周报

**动机**：家长是最主要的“决策者”，但他们不一定会陪练，需要一个一眼能看懂的周度总结。

**入口**：顶部导航「👨‍👩‍👧 周报」。按**当前档案**统计，切换档案后内容随之变化。

**统计窗口**：以今天为终点，向前 7 天（含今天），日期区间显示在标题右侧。

**内容**：

| 区块 | 内容 |
|---|---|
| 周评级 | 按坚持度、正确率、练习量综合计算：🌟 非常棒 / 👍 不错 / 🙂 有进步空间 / 💪 需多练 / 🌱 未开始 |
| 关键指标 | 练习天数（x/7）、练习次数、一次答对率、连续天数 |
| 每日练习量 | 7 根柱状图，标注日期与星期，空白日显示灰柱 |
| 练了什么 | 识谱 / 跟练 / 视奏 / 乐理 / 节奏 各自的次数与占比条 |
| 需要加强的音 | 错题本前 3 个音（音名 + 错误次数） |
| 课程与成就 | 已完成课程数、累计星数、徽章数、XP |
| 给家长的建议 | 最多 3 条，按优先级生成（见下） |

**建议生成规则**（按优先级取前 3 条）：

1. 没有练习 → 建议从每天 5 分钟识谱开始。
2. 练习天数 ≤2 → 建议固定时间段；≥6 → 肯定坚持。
3. 一次答对率 <70% → 建议放慢看清谱号；≥90% → 建议加难度或试视奏。
4. 有错 ≥3 次的音 → 建议去错题本做专项练习。
5. 练习量够但没跟练 → 建议去曲谱库跟弹。
6. 练习量够但没做乐理 → 建议抽 5 分钟做乐理。

**文字版**：点「📋 复制文字版」把整份周报复制到剪贴板（含区间、指标、薄弱音、建议），
方便直接发给家人；剪贴板不可用时自动退化为 `execCommand`。

**评级算法**：坚持度（最高 40）+ 正确率（最高 40）+ 练习量（最高 20），
≥75 星、≥55 不错、≥30 有进步空间，其余需多练。

**入口**：周报页顶部「⚡ 每日挑战」卡片。

**规则**：

| 项 | 规则 |
|---|---|
| 题量 | 每天 8 题（6 道识谱 + 2 道乐理） |
| 限时 | 60 秒 |
| 出题 | 由「日期 + 档案 ID」生成固定种子，**同一天同一档案题目固定**，刷新不换题 |

## 10. 游戏化系统

### 10.1 经验与等级

- XP 来源：识谱练习答对（一次答对 +3，答错后答对 +2）。
- 升级需求：第 N 级需 `20 + (N−1) × 5` XP（20 / 25 / 30 / 35 …）。
- 升级时全屏庆祝。
- ⚠️ 现状偏差：XP 条在答题当次不刷新，滞后一题（§10.2-10）。

### 10.2 连续练习天数

- 定义：**每天至少答对 1 题**即为有效练习日。
- 连续有效日累计 `dayStreak`；中断时消耗 1 次“冻结”保留连击（初始 2 次）。
- 冻结次数不补充、无 UI 展示。

### 10.3 每日任务

## 11. 非功能规格

### 11.1 数据与持久化

- **存储**：单一 `localStorage` 键 `music-tutor-v1`，整棵状态 JSON。
- **校验**：加载时对枚举值、数值、对象结构做白名单校验；损坏数据回退默认值，不白屏。
- **迁移**：旧版数字课程 ID（1–30）自动映射到新 ID，保留星级。
- **容量**：全部数据 < 10 KB。
- **隐私**：无网络请求、无埋点、无账号；麦克风音频只在本地处理，不上传。

### 11.2 渲染

- 五线谱：SVG，线距 12px，viewBox 高度按音符/加线范围自适应（88 键极端音高也不裁剪）。
- 谱号：内置 Bravura 轮廓（SIL OFL 1.1），1 em = 4 个线距，G 谱号锚第二线、F 谱号锚第四线；不依赖系统字体，离线与 iPad 显示一致。
- 键盘：白键 flex 均分，黑键按白键比例百分比定位。
- 主题：CSS 变量切换，首帧内联脚本预读主题防闪烁。

### 11.3 音频

- Web Audio 加法合成（6 个三角波泛音），无音频文件。
- 复音上限 12；首次用户手势解锁 iOS AudioContext。
- 全部音效受“声音”开关控制。

### 11.4 离线与部署

- 静态托管即可（GitHub Pages / Netlify / 本地 `node server.js`）。
- Service Worker 预缓存应用壳、全部脚本、样式、图标；cache-first。
- 麦克风与 Service Worker 需要 https 或 localhost；局域网 http 下自动降级。

### 11.5 性能目标

- 首屏可交互 < 1s（本地）。
- 答题反馈 < 50ms。
- 跟练检测帧率 ≥ 30fps（iPad 2019 及以上）。
- 总资源 < 200KB（不含图标）。

### 11.6 可访问性（目标 WCAG 2.1 AA，当前部分达标）

已具备：

- 导航：`role="tablist"` + `aria-selected` / `aria-controls` / `aria-labelledby`，漫游 tabindex，
  支持 ← → ↑ ↓ Home End 切换，焦点跟随。
- 琴键：`role="button"`、可读名称（如“C4 键”“C♯4 黑键”）、整组一个 Tab 位、方向键移动、回车/空格激活。
- 谱面音符（学习页）：`role="button"`、可读名称（如“D4 · Re”）、回车/空格激活，重绘后焦点自动恢复。
- 列表项（曲目 / 课程）：`role="button"`、`aria-label` 含状态、锁定课程 `aria-disabled` 且不可聚焦。
- 跳转链接「跳到主要内容」、`role="status" aria-live="polite"` 反馈、统一 `:focus-visible` 焦点环。
- `prefers-reduced-motion`：关闭彩带、闪烁、过渡动画。
- `touch-action: manipulation`：消除 iPad 双击缩放与点击延迟。
- 答案按钮亮黄/绿/青改为深色文字，提升对比度。

- segmented 控件（谱号/难度/写法/八度/模式/速度/训练营标签）统一维护 `aria-pressed`。
- 徽章卡片常驻显示说明文字与获得日期，未获得时显示“未获得”（不再只依赖 `title`）。
- 庆祝遮罩：`role="alertdialog"` + `aria-label`，可点击任意处或按 Esc/Enter/空格提前关闭。
- 点击目标：导航、图标按钮、文字按钮均 ≥44px；segmented ≥38px。
- 移动端：`viewport-fit=cover` + 安全区内边距；横屏压缩留白使谱面与键盘同屏；
  平板加大琴键与按钮；横向滚动区启用 `overscroll-behavior` 与惯性滚动；长按不选中文字。

已全部完成，无遗留项。
